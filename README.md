## Overview

Traditional Deep Q-Networks rely on reward signals as the **sole source of supervision**.
We introduce the **Markov Logic Process (MLP)**, a six-tuple **(S, A, P, R, γ, 𝓛)** that
extends the classical MDP with a **Logos module** — an asynchronous online symbolic
reasoner that continuously mines Apriori association rules from the agent's own
experience replay buffer and translates them into a shaping bonus **Φ_L(s, a)**.

The Logos-augmented Bellman operator is:

$$V_\mathcal{L}(s) = \max_{a \in A}\bigl[R(s,a) + \lambda\,\Phi_\mathcal{L}(s,a) + \gamma\,V_\mathcal{L}(s')\bigr]$$

### Key Results (LunarLander, 5 seeds each)

| Environment | Agent | Eval Mean ± Std | Ep. to Solve | vs. Baseline |
|-------------|-------|-----------------|--------------|--------------|
| LL-Std | MDP (DQN) | 218.1 ± 31.5 | 352.4 ± 44.6 | — |
| LL-Std | MLP-Bellman | 241.3 ± 22.3* | 298.2 ± 37.8* | +10.6% |
| LL-Std | **MLP-Full** | **265.3 ± 17.2**\*\* | **248.6 ± 31.2**\*\* | **+21.7%** |
| LL-Wind | MDP (DQN) | 191.1 ± 38.4 | 421.0 ± 67.3 | — |
| LL-Wind | MLP-Bellman | 223.7 ± 28.1* | 352.6 ± 51.4* | +17.1% |
| LL-Wind | **MLP-Full** | **251.1 ± 21.4**\*\* | **287.4 ± 43.1**\*\* | **+31.4%** |

Significance vs MDP baseline (Welch t-test): \* p<.05, \*\* p<.01. Cohen's d = 1.23 (MLP-Full vs MDP on LL-Wind).

## Quick Start

### Option A — Run on Kaggle (recommended, free T4 GPU)

1. Fork this repo or download the notebooks.
2. Create a new Kaggle notebook, upload `notebooks/01_train.ipynb`.
3. Enable **GPU T4** and **Internet access** in Settings.
4. Run all cells. The notebook auto-resumes if interrupted.
5. After training, run `02_eval.ipynb` for figures, then `03_video.ipynb` for videos.

### Option B — Local installation

```bash
# Clone
git clone https://github.com/saiyamjain/markov-logic-process.git
cd markov-logic-process

# Install (editable mode)
pip install -e ".[dev]"

# Install system dependency for Box2D
sudo apt-get install swig build-essential

# Run unit tests
pytest tests/ -v

# Train (all envs + seeds, ~3–4 hr on a T4)
cd notebooks && jupyter nbconvert --to notebook --execute 01_train.ipynb
```

## Module Details

### The Logos Module

```
L = (D, B, F, τ)
```

| Component | Description |
|-----------|-------------|
| **D** | Sliding-window experience database (W = 2,000) |
| **B** | Hybrid EW+EF feature discretiser → {Low, Med, High} bins |
| **F** | Mined Apriori rule set (σ=0.20, κ=0.80) |
| **τ** | Background thread — mines every Δ=2,000 steps without blocking DQN |

**Logic Potential (Eq. 6):**

$$\Phi_\mathcal{L}(s,a) = U_\mathcal{L} \cdot \sum_{r \in \mathcal{F}} \text{match}(r,s,a) \cdot \kappa_r \cdot \min(\rho(r), 5)$$

where U_L is the global confidence estimate, κ_r is rule confidence, ρ(r) is persistence count.

### Agent Variants

| Variant | TD Target | Action Selection | Description |
|---------|-----------|------------------|-------------|
| **MDP** | Standard Bellman | Q-greedy | DQN baseline (λ=0) |
| **MLP-Bellman** | Logos-augmented | Q-greedy | Ablation: Bellman only |
| **MLP-Full** | Logos-augmented | Q+Φ_L greedy | Full proposed model |

## Hyperparameters

All hyperparameters match the paper exactly. Defined in `configs/default.yaml`:

```yaml
dqn:
  hidden_units: [64, 64]
  lr: 1.0e-3
  gamma: 0.99
  batch_size: 64
  replay_capacity: 10000
  target_update_freq: 100
  eps_decay_episodes: 300

logos:
  lambda_scale: 1.5
  window_size: 2000
  mine_interval: 2000
  min_support: 0.20
  min_confidence: 0.80
  persistence_threshold: 3
  persistence_cap: 5
  deduction_threshold: 0.90
```
